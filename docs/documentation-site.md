# Documentation Site

The documentation website lives in `apps/docs` and is powered by VitePress.

## Commands

- `npm run docs:dev`
- `npm run docs:build`
- `npm run docs:preview`

## Structure

- `apps/docs/docs/index.md`: marketing homepage
- `apps/docs/docs/api/*`: API section pages
- `apps/docs/docs/.vitepress/config.ts`: navigation + sidebar
- `apps/docs/docs/.vitepress/theme/custom.css`: visual customization
